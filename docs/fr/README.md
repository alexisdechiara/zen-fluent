# Documentation en français

La documentation de Zen Fluent en français. L'anglais reste la référence :
chaque page indique la page anglaise qu'elle traduit.

- [Présentation](../../README.fr.md) : le README du projet.
- [Installation](installation.md) : l'installateur Windows, Sine, Mica For
  Everyone, le flou sous Linux, l'installation manuelle.
- [Zen Fluent](core.md) : ce que le mod habille, le style Edge,
  l'accessibilité.
- [Réglages](settings/README.md) : une page par groupe de réglages.
- [Zen Fluent Enhanced](enhanced.md) : chaque fonction du second mod.
- [Compatibilité avec les autres mods](compatibility.md).
- [Contribuer](contributing.md).

Les noms des réglages sont donnés tels que Sine les affiche, en anglais ; Zen
Fluent Enhanced les traduit dans sa page de réglages quand Zen est en
français. Une erreur de traduction ? Ouvrez une
[issue](https://github.com/alexisdechiara/zen-fluent/issues).
